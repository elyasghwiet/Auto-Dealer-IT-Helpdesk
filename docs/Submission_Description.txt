For my Week 4 project I built an IT helpdesk for a fictional electric-vehicle fleet operator in Ahmedabad with 80 employees, using the open-source GLPI service desk running in Docker. I created ten ITIL ticket categories, three support groups with technician accounts, and business rules that automatically route each ticket to the right group, for example network and security tickets to Infrastructure L2 and charging-software tickets to Fleet Applications Support. I also configured eight service levels (first response from 15 minutes to 4 hours, resolution from 4 to 72 hours) with rules that apply them by priority, and I tested this on a live Urgent ticket where GLPI set both deadlines automatically.

The repository contains 18 plain-language knowledge-base articles, a log of 40 simulated tickets covering Windows, Linux and network problems with troubleshooting steps, a Bash disk-cleanup script with a safe dry-run default, a PowerShell onboarding script with WhatIf support, an asset inventory workbook with formulas, and a simulated monthly helpdesk report showing 92.5 percent SLA compliance. The report also explains how competing urgent tickets are prioritised.

I am open about the limits: the ticket data is simulated, the email-to-ticket receiver was configured but not tested with a live mailbox, only eight tickets and five articles were entered in GLPI, and the self-service portal was not built. I also documented an incident where GLPI lost data after restarts, how I recovered it, and the backup scripts I added to prevent it. The Word report includes screenshots of every configuration step.
