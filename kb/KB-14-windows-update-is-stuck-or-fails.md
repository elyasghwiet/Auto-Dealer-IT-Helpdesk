# KB-14: Windows Update is stuck or fails

**Category:** Software and Licences  |  **Applies to:** Windows 11

## The problem
Updates stay at the same percentage for a long time or fail with an error.

## Fix it yourself
1. Wait at least 30 minutes; some updates are large.
2. Restart the laptop and try Settings, Windows Update, Check for updates again.
3. Open Settings, System, Troubleshoot, Other troubleshooters, and run the Windows Update troubleshooter.
4. Make sure the disk has at least 15 GB free (see KB-06).
5. If it still fails, tell us the error code shown.

**[SCREENSHOT]** The Windows Update page; the troubleshooter result.

## Still not working?
We can reset the update cache from the command line (support staff only).

## How to avoid it
Leave the laptop plugged in and on during updates.
