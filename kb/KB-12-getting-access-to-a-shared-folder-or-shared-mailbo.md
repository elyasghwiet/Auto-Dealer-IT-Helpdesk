# KB-12: Getting access to a shared folder or shared mailbox

**Category:** Accounts and Access  |  **Applies to:** Windows file shares and Exchange shared mailboxes

## The problem
You moved teams or the folder suddenly says 'access denied'.

## Fix it yourself
1. Check the exact folder path from the e-mail or ticket.
2. Ask your manager to approve access in the ticket.
3. We add you to the correct security group. Access normally works after you sign out and sign in.
4. For a shared mailbox, restart Outlook and wait up to 30 minutes for it to appear.

**[SCREENSHOT]** The 'Access denied' message with the folder path.

## Still not working?
If it still does not appear, send us a screenshot of the error and the path.

## How to avoid it
Do not share passwords to open someone else's folder; ask for proper access.

Category and priority: Accounts and Access, Low (Medium if work is blocked)
