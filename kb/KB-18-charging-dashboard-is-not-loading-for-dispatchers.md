# KB-18: Charging dashboard is not loading (for dispatchers)

**Category:** Fleet and Charging Software  |  **Applies to:** Fleet charging web dashboard

## The problem
The charging dashboard shows an error or never loads and vehicles cannot be scheduled.

## Fix it yourself
1. Refresh with Ctrl+F5 and try another browser.
2. Check other web pages work; if not, see KB-07.
3. If other pages work, report it immediately as Urgent: vehicles may be waiting to charge.
4. Give us the time, the page address and a screenshot of the error.
5. Use the manual charging checklist from the dispatcher binder until we confirm it is fixed.

**[SCREENSHOT]** The dashboard error page.

## Still not working?
Support staff: check the application service on the server and read its log.

## How to avoid it
Report slowness early; a service that restarts at night can fail after backups.

## Open a ticket
Category and priority: Fleet and Charging Software, Urgent
