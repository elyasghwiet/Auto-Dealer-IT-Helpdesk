# KB-10: Sending large files (over 20 MB)

**Category:** Email  |  **Applies to:** Outlook

## The problem
Your message bounces with 'message too large'.

## Fix it yourself
1. Company mail accepts attachments up to 20 MB in total.
2. Save the file in the shared folder or cloud drive and right-click it, then choose Copy link.
3. Paste the link in your e-mail. Check who can open it.
4. For very large files (video, drawings), ask us for a temporary upload area.

**[SCREENSHOT]** The Copy link option on a shared file.

## Still not working?
If the link says 'access denied', share the folder with the recipient's name.

## How to avoid it
Zip large folders and remove unused images before sending.
