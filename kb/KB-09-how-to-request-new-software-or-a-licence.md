# KB-09: How to request new software or a licence

**Category:** Software and Licences  |  **Applies to:** Windows 11

## The problem
You need a program that is not installed.

## Fix it yourself
1. Check the approved software list on the intranet. Approved programs can be installed by us in minutes.
2. Create a ticket in the Software and Licences category with the program name and why you need it.
3. Your manager approves the request when a licence costs money.
4. We install the program remotely or ask you to be present. Do not download installers yourself.

**[SCREENSHOT]** The ticket form with the category selected.

## Still not working?
If the program is not on the list, we check security and cost before we approve it.

## How to avoid it
Request software at least two working days before you need it.

## Open a ticket
Category and priority: Software and Licences, Medium or Low
